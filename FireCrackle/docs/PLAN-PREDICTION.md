Use the nearest trusted anchor by PTS, with earlier-frame tie break. Within a configurable local window, intersect the unit-width fractional clock-phase constraints from other trusted labels, starting with the nearest. Stop when evidence is incompatible (lag/reset/wrong label), rather than averaging it away. Primary comes from the surviving phase interval; keep the closest alternate supported by phase or half-frame capture uncertainty. This is a nominal clock prediction, not a texture detector or proof that lag cannot occur. Source sheet/mirror are preserved; normalized rows are comparable across sheets.

New settings: calibration window seconds and capture uncertainty in local indexed frame intervals (default half a frame). Existing suggest_max_seconds still limits distance from trusted evidence. Inferred labels are not calibration anchors: persist an optional predicted flag in version2 log entries, preserve through compaction/replay/undo, and remove only on an explicit manual label edit. Old logs without the flag remain trusted because their historical source is unknown.

Dedicated manualStep/manualBigStep IPC actions accept the departing unset frame's primary suggestion (if moving forward to a different frame), then move once by the requested amount, independent of configured auto-advance. Existing step/bigStep remain plain navigation for playback. Seek/backward/zero/end/no-suggestion do not write. Undo restores both label and provenance; autosave and reopening must retain it. UI owner wires explicit forward buttons; toUiAction distinguishes manual keyboard steps automatically. Destination View.suggestion remains the preview-sync contract.
